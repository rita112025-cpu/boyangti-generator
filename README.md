# 伯洋體產生器 2.3｜空話製造研究所 THE RHETORIC LAB

> 把一句話，說成一場宇宙。

**政治語言觀察 × 諷刺創作**

輸入一個日常主題，讓抽象名詞開始工作。聽起來很有道理，至於怎麼做……我們再對齊。

Live Demo: https://rita112025-cpu.github.io/boyangti-generator/

### ✨ 功能

六個分頁：

- **01 論述生成**：18 種伯洋體句型，搭配抽象濃度 0-100%（從「還聽得懂」到「平行宇宙」）與自訂 ABCD 配方；可一鍵複製、隨機一篇、再抽象一點
- **02 回覆模擬**：輸入對方的說法，選句型與抽象濃度，產生一段伯洋式回覆
- **03 句型拆解**：貼上一段論述，偵測最接近的句型、估算抽象濃度、列出抽象詞彙並逐句標記
- **04 空話剝除**：劃掉抽象詞，估算剩下多少實質內容，剩下的片段可一鍵複製
- **05 白話翻譯**：一句大白話翻成伯洋體，分標準版、加強版、極致版，並顯示字數膨脹倍數
- **06 晶晶體**：把中文常見詞換成英文，分輕度、中度、重度，可再轉一次與複製

其他：

- **暗版／亮版**：右上角切換，會記住選擇，預設跟隨系統
- **純本機運作**：無需登入、無需 API，只需一點想像力

### 🚀 快速開始

直接打開 `index.html` 即可使用，這是單檔應用，無需安裝。

### 📁 專案結構

```
boyangti-generator/
├── index.html         # 打包後的單檔網頁（GitHub Pages 直接使用）
├── App.tsx            # 主程式原始碼（React）
├── index.css          # 樣式（Tailwind 與主題變數）
├── package.json
├── package-lock.json
└── README.md
```

`index.html` 是由 `App.tsx` 與 `index.css` 以 Vite 打包並內嵌成單檔；打包設定目前尚未放進 repo。
