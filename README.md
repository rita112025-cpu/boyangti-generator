# 伯洋體產生器 2.3｜空話製造研究所 THE RHETORIC LAB

> 把一句話，說成一場宇宙。

**政治語言觀察 × 諷刺創作**

輸入一個日常主題，讓抽象名詞開始工作。聽起來很有道理，至於怎麼做……我們再對齊。

Live Demo: https://your-name.github.io/boyangti-generator/

[Preview](./preview.png)

### ✨ 功能

- **16 種伯洋體句型**：結構性框架、定義繞圈、城市廊帶、ABCD因果接龍、風險治理體、資訊透明體、韌性防禦體、對齊共識體、滾動修正體、盤點機制體、跨域整合體、廊帶經濟體、數位賦能體、多元共榮體、價值疊加體、戰略縱深體
- **抽象濃度 0-100%**：從「還聽得懂」到「進入平行宇宙」
- **自訂 ABCD 配方**：A·對象 B·起點概念 C·中介效益 D·終極願景
- **純本機運作**：無需登入、無需 API，只需一點想像力
- 一鍵複製、隨機一篇、再抽象一點

### 🚀 快速開始

```bash
# 1. 安裝
npm install

# 2. 本地開發
npm run dev

# 3. 打包
npm run build
```

直接打開 `index.html` 也能跑，這是單檔應用。

### 🔧 句型公式

| 句型 | 公式 |
|------|------|
| 結構性框架 | 拉高層次 → 拆成變項 → 追問依據 → 持續討論 |
| 定義繞圈 | 定義A → 否定極端 → 保留詮釋空間 → 回到定義 |
| 城市廊帶 | 指認節點 → 劃出廊帶 → 疊加價值 → 願景閉環 |
| ABCD因果接龍 | A→B→C→D |
| 其他12式 | 各有獨立模板，詳見原始碼 `PATTERNS` |
